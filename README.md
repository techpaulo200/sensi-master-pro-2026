O **Sensi Master 2026** é um calibrador de sensibilidade web moderno, leve e otimizado, desenvolvido focado na experiência de jogadores que buscam ajustar e salvar suas configurações de mira de forma rápida e intuitiva.

---

## 🚀 Funcionalidades

*   🎛️ **Controle Preciso:** Sliders de ajuste com escala atualizada de 0 a 200 (Geral, Red Dot, Mira 2x e Mira 4x).
*   💾 **Persistência de Dados:** Integração com `localStorage` do navegador para garantir que suas configurações não sumam ao fechar a página.
*   📱 **Interface Mobile-First:** Design limpo, responsivo e com estilo *cyberpunk/gamer* perfeito para visualização em smartphones.
*   ⚡ **Abas Dinâmicas:** Sistema leve de navegação entre as telas de Configuração e Dev Logs.
*   🔔 **UI Fluida:** Notificações em tempo real (Toast) integradas ao design do app, eliminando alertas nativos intrusivos.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído de forma nativa e otimizada para rodar em qualquer hardware, sem a necessidade de scripts pesados ou frameworks externos:

*   **HTML5:** Estruturação semântica.
*   **CSS3:** Estilização responsiva, variáveis nativas (`:root`) e animações de fade-in.
*   **JavaScript (Vanilla):** Lógica de manipulação do DOM e armazenamento local.

---

## 📦 Como Executar o Projeto

Como o projeto é feito em tecnologias web puras, você não precisa instalar nada!

1. Faça o clone do repositório ou baixe o arquivo `.html`.
2. Abra o arquivo `index.html` em qualquer navegador (Chrome, Edge, Firefox, Safari).
3. Ajuste os sliders e clique em **Salvar Settings**.
